# TubeForge

**Download. Study. Clip.**

Self-hosted web app that downloads and converts media from YouTube and 1000+ other sites, turns talks into study material, cuts FFmpeg clips, and identifies songs — all processed on your own machine.

## What it does

TubeForge is a local Node.js + Express studio. You paste a link (or pick a platform), the server extracts metadata through **yt-dlp** / **ytdl-core**, and FFmpeg handles conversion and clipping. Nothing is uploaded to a third-party “cloud downloader”: files, transcripts, and history stay on the host.

### Downloader

- Paste a URL from YouTube, TikTok, Instagram, Facebook, X, Twitch, VK, OK.ru, and many more (yt-dlp extractor list).
- Inspect video/audio formats, codecs, bitrate, and size.
- Download original streams or convert while streaming: **MP4, WebM, MKV, MOV**, plus audio **MP3, AAC, M4A, ALAC, FLAC, WAV, Opus, OGG**.
- Video+audio merge when the source is split.
- Age-gated / private posts can use a Netscape or JSON **cookies** file (`COOKIES_FILE`).

### Playlist

- Load a playlist, select videos, and run a download queue with chosen quality and container.
- Stop, skip, or clear the queue; long playlists are capped (`MAX_PLAYLIST_ITEMS`, default 400).

### AI Study Mode

- Captions become a **summary**, **key concepts**, and a **quiz**, plus a searchable interactive transcript (click a line to seek).
- No caption track: optional **local Whisper** (`whisper.cpp`) transcribes audio on the server, with VAD to skip music/silence.
- With `ANTHROPIC_API_KEY`, notes are generated by Claude; without a key, a built-in **offline analyser** still works.

### FFmpeg Clip Studio

- Trim a time range (default max 10 minutes).
- Burn in title overlay, watermark, subtitles, and a progress bar.
- Output **MP4 / WebM / MKV / MOV** or a short **GIF**.
- Renders run server-side; recent clips are listed and expire after `CLIP_RETENTION_HOURS` (default 24).

### Audio ID

- Identify a song from the microphone or system audio (HTTPS or localhost required for capture).
- Default: AudD (free tier). Optional token or **ACRCloud** as primary, AudD as fallback.

### History & UI

- Download and recognition history in **SQLite** (`data/tubeforge.db`).
- Dark / light theme.
- Interface languages: **English, Azərbaycan, Русский, Türkçe**.

## Stack

| Layer | Tech |
| --- | --- |
| Server | Node.js ≥ 18.17, Express |
| Media | `@distube/ytdl-core`, yt-dlp, FFmpeg (`fluent-ffmpeg`) |
| Data | better-sqlite3 |
| Speech (optional) | whisper.cpp |
| Study AI (optional) | Anthropic Claude |
| Frontend | static HTML / CSS / JS in `public/` |

## Requirements

- [Node.js](https://nodejs.org/) 18.17 or newer
- [FFmpeg](https://ffmpeg.org/) (or `ffmpeg-static` optional dependency)
- **yt-dlp** recommended for non-YouTube sites and as fallback (`npm run setup:ytdlp`)

## Quick start

```bash
git clone <repo-url>
cd TubeForge
npm install
npm run setup:ytdlp
cp .env.example .env
npm start
```

Open [http://localhost:3000](http://localhost:3000).

Development with auto-reload:

```bash
npm run dev
```

Optional local speech-to-text for Study Mode when videos have no captions:

```bash
npm run setup:whisper
```

Better models for Azerbaijani/Turkish (example):

```bash
WHISPER_MODEL=small npm run setup:whisper
```

## Configuration

Copy `.env.example` to `.env`. All keys are optional.

| Variable | Role |
| --- | --- |
| `PORT` | HTTP port (default `3000`) |
| `MEDIA_ENGINE` | `auto` (ytdl then yt-dlp), `ytdl`, or `ytdlp` |
| `YTDLP_PATH` / `FFMPEG_PATH` | Explicit binaries if not on PATH |
| `COOKIES_FILE` | Cookies for restricted / bot-gated media |
| `ANTHROPIC_API_KEY` / `STUDY_MODEL` | Claude study packs |
| `MAX_CLIP_SECONDS`, `MAX_GIF_SECONDS`, `MAX_TRANSCODE_SECONDS` | Render/convert limits |
| `CLIP_RETENTION_HOURS` | How long clip files are kept |
| `WHISPER_*` | Local transcription binary/model |
| `AUDD_API_TOKEN`, `ACR_*` | Audio identification |

## Useful scripts

```bash
npm start              # production server
npm run dev            # watch mode
npm run setup:ytdlp    # fetch yt-dlp into ./bin
npm run setup:whisper  # build whisper.cpp + models
npm run reset-db       # recreate SQLite database
```

Health check: `GET /api/health`.
